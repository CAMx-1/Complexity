# Complexity Player

An Alexa skill for watching your own Plex Media Server on an Echo Show, by
voice and touch. It's built first for the Echo Show 11 and replaces the
official Plex skill, which was shut down on June 15, 2026. It is video only;
for music, use an existing Plex music skill.

Status: in development. Running on Echo Show in the Development stage, with Plex sign-in, video playback, a loading screen, and touch home and server screens. Say "Alexa, open complexity player".

Not affiliated with or endorsed by Plex, Inc. or Amazon.

## Privacy Policy
Complexity Player stores only your Plex sign-in, your chosen server and your
playback position, so it can play your own library. It doesn't sell or share
data or use analytics. "Unlink Plex" or disabling the skill deletes it all.
See [PRIVACY.md](PRIVACY.md).
